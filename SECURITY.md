# Security Policy

## Reporting a vulnerability

Please report security issues **privately** through GitHub: open the repository's **Security** tab and
choose **Report a vulnerability** (private security advisories). Do not open a public issue for
anything that could be exploited.

Include what you found, how to reproduce it, and the affected files or versions. Reports are handled on
a best-effort basis.

## Supported versions

Only the latest release and the `main` branch receive fixes.

## Scope

This covers the installer and tooling in this repository (PowerShell scripts, build and validation
tools). It does not cover Apple or Microsoft fonts or software.
